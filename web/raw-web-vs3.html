Documentation Concepts

Research behind every pipeline decision. The structural backbone mapped across four core areas.

Foundation Decisions

  • Data Loading: Raw JSONL streaming from UCSD to achieve 0 GB disk cache.
  • Storage: Apache Arrow format for zero-copy memory mapping.
  • Balancing: Uncapped undersampling to the minority class (Neutral).

Methodology & Pipeline

  • EDA Voice: Transitioned from assertive to research tone.
  • Stopwords: Hybrid approach using NLTK + Domain specifics.
  • ETL Caching: Saving narrow CSVs with only computed columns.

Advanced Topics

  • Cross-Notebook Audits: Fixed 15 environment asymmetry bugs.
  • Clustering Math: Validated MiniBatchKMeans empirically.
  • Embedder Upgrade: Selected `nomic-embed-text-v1.5`.

Enterprise-Grade (Deferred)

  • Professional Clustering: BERTopic + HDBSCAN recommended.
  • Efficient Fine-Tuning: LoRA (Low-Rank Adaptation) documented for VRAM constraints.
