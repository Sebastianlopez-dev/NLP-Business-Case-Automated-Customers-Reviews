Natural Imbalance

213.9K

We processed 33 categories. However, the data revealed an 81.6% positive skew. The minority class dictated the final balanced corpus size. We discarded ~728K positive reviews.

Word Count Limit

98.5%
fit in 128 tokens

Median length is 27 words. Truncating at max_length=128 yields a 4× training speedup with negligible signal loss (<1.5%).

Data Quality

8.4%
duplicates

81,901 duplicated wildcards (e.g. "Great", "Good"). This strict noise filter prevents model overfitting on low-signal repeats.

Decision Discarded Alternative Rationale (N01 EDA)
Stream gzip from UCSD HF datasets streaming Avoided unstable Hugging Face API errors and duplicate caching on local disk.
Merge all 33 categories 1-2 specific categories Maximizes lexical diversity to prevent the model from merely memorizing category-specific nouns.
Uncapped Undersampling SMOTE / Class weights Maintains data transparency with 100% real human text. No synthetic artifacts introduced.
Noise Filter len < 10 No filter / len < 20 Optimal tradeoff to remove 8.4% of duplicate wildcards (e.g. "Great") without losing valid short complaints.
Apache Arrow format CSV / Parquet Provides zero-copy memory mapping, enabling native ultra-fast streaming in HF Trainer.
Tokenizer max_length=256 max_length=512 Truncating to 256 tokens captures ~98%+ of reviews while reducing quadratic attention time, yielding a massive training speedup.
