MiniBatchKMeans: Scalability

While traditional K-Means exhausts memory attempting to calculate all distances simultaneously, MiniBatchKMeans iterates over stochastic batches, avoiding OOM while empirically maintaining 99% of the Silhouette Score.

Embeddings Upgrade

Replaced MiniLM with nomic-embed-text-v1.5. This 137M model projects the corpus into 768 dimensions, offering a substantial 10-point leap in MTEB clustering performance metrics.

Extractive-Abstractive Workflow

Processing massive volumes directly in an LLM context window is not economically viable and promotes hallucinations.

  • 1. Strict Extraction (Python): Deterministic calculations of key heuristics (volume, dominant polarity, TF-IDF vectors).
  • 2. Conditioned Abstraction: We inject a structured JSON payload into Mistral Medium 3.5 (128B) via the NVIDIA API, strictly limiting its task to functional narrative formatting.

JSON Injection (Facts)

Documentation Concepts

Research behind every pipeline decision. The structural backbone mapped across four core areas.

Foundation Decisions

  • Data Loading: Raw JSONL streaming from UCSD over HF full download to achieve 0 GB disk cache.
  • Storage: Apache Arrow format for zero-copy memory mapping vs CSV parsing.
  • Balancing: Uncapped undersampling to the minority class (Neutral) to maintain ~400K viable samples.

Methodology & Pipeline

  • EDA Voice: Transitioned from assertive to research tone, testing hypotheses instead of stating facts.
  • Stopwords: Hybrid approach using NLTK (179) + Domain specifics (23) for cleaner TF-IDF matrices.
  • ETL Caching: Saving narrow CSVs with only computed columns, joining with main Arrow files via `pd.merge()`.

Advanced Topics

  • Cross-Notebook Audits: Fixed 15 environment asymmetry bugs (e.g., hardcoded arrays, stale paths).
  • Clustering Math: Validated MiniBatchKMeans empirically against pure K-Means and LDA topic modeling.
  • Embedder Upgrade: Selected `nomic-embed-text-v1.5` over ModernBERT due to encoding speed tradeoffs.

Enterprise-Grade (Deferred)

  • Professional Clustering: BERTopic + HDBSCAN recommended for production over K-Means for dynamic noise handling.
  • Efficient Fine-Tuning: LoRA (Low-Rank Adaptation) documented for VRAM constrained scaling, deferred due to T4 hardware surplus.
