Sentiment Metrics

The operational trade-off: computational speed versus contextual depth. Champion vs Baseline analysis.

DistilBERT

Baseline
Foundation Knowledge Distillation (Sanh et al., 2019). Trained to mimic BERT's probability distribution using only 66M parameters.
The Limit Struggles with complex heuristics and irony (e.g., "I love that it breaks in two days"), prioritizing isolated polar tokens.

RoBERTa

Champion
Foundation Massively re-optimized BERT (Liu et al., 2019). Trained with Dynamic Masking and 125M parameters.
The Advantage Resolves non-linear irony. Correlates extended syntax ("love") with defect verbs ("breaks").

The Architect vs The Mover

K-Means is the architect who measures every wall before placing furniture. It acts as our gold-standard baseline, but loads the full n-dimensional set into memory, failing to scale.

MiniBatchKMeans is the fast mover. It iterates over stochastic batches, avoiding OOM while empirically maintaining 99% of the Silhouette Score. We hired the mover to handle 571M rooms.

Lightweight Embeddings

Processed using all-MiniLM-L6-v2. With a mere 22 MB footprint, it projects massive corpora into 384 dimensions without saturating RAM.

Semantic Synthesis

Executive abstraction of latent topologies using Foundational Models (LLMs).

Extractive-Abstractive Workflow

Processing massive raw volumes directly in an LLM context window is not economically viable and promotes hallucinations.

  • 1. Strict Extraction (Python): Deterministic calculations of key heuristics (cluster volume, dominant polarity, TF-IDF vectors).
  • 2. Conditioned Abstraction (LLM API): We inject a structured JSON payload into Mistral Medium 3.5 (128B), limiting its task exclusively to functional narrative via the NVIDIA API.

JSON Injection (Facts)

{
  "cluster": "Logistics",
  "volume": 14500,
  "sentiment": "87% Neg"
}

Mistral 128B Output

"The highest operational churn risk lies within logistics, a sector grouping 14,500 users with a predominant 87% negativity rate, primarily focused on delivery delays."
